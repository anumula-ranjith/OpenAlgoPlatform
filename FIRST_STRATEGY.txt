2. UNDERSTAND THE FIRST SIGNAL RULE
Data: NIFTY index on NSE_INDEX, using completed five-minute candles.
Fast line: 5-period exponential moving average of closing prices.
Slow line: 20-period exponential moving average of closing prices.
BULLISH_CROSS: fast EMA moves from at/below the slow EMA to above it.
BEARISH_CROSS: fast EMA moves from at/above the slow EMA to below it.
WAIT: neither crossover happened on the candle being examined.
The indicator carries its EMA history across sessions; it does not reset daily.
At least 21 completed candles are required. Repeated polling does not emit
the same completed candle again. These are learning rules, not evidence of
profitability or a recommendation to buy or sell a particular contract.

3. RUN A READ-ONLY ANALYZER READINESS CHECK
In PowerShell, from D:\Projects\OpenAlgoPlatform:
    .\.venv\Scripts\python.exe strategies/examples/first_nifty_strategy.py --mode check --local-key
The local-key option reads your existing encrypted OpenAlgo key into memory.
It does not display the key or save a plaintext copy. In the built-in Python
host, OpenAlgo injects OPENALGO_API_KEY instead, so no local-key flag is needed.
The script stops if it cannot confirm Analyzer mode through the public API.

4. REPLAY THE HISTORICAL SIGNALS
    .\.venv\Scripts\python.exe strategies/examples/first_nifty_strategy.py --mode replay --local-key --start-date 2026-11-16 --end-date 2026-11-23 --report tmp/first_nifty_signal_replay.json
Prepared test result: 438 completed candles, 5 bullish crossovers, 5 bearish
crossovers, and zero orders. Inspect the JSON report for the exact candle times.
This is a historical SIGNAL replay. It is not an Analyzer fill test, a trade
simulation with P&L, or a profitability backtest. No entry/exit prices, contract
returns, costs, slippage or currency P&L have been modeled.

5. MONITOR SIGNALS DURING AN OPEN NSE SESSION
    .\.venv\Scripts\python.exe strategies/examples/first_nifty_strategy.py --mode monitor --local-key --minutes 15
The monitor prints new completed-candle events for a bounded 15-minute run.
It refuses to start the monitor when the calendar says NSE is closed.
It still submits no orders. Ctrl+C stops monitoring.
24-Nov-2026 is an NSE equity/F&O holiday; the preparation run correctly found
the session closed. The next scheduled regular session is 25-Nov-2026.
Reference: https://nsearchives.nseindia.com/content/circulars/FAOP71777.pdf

6. SELECT THE INSTRUMENT FOR THE ANALYZER ORDER STAGE
NIFTY on NSE_INDEX is an index reference and cannot itself be bought or sold.
Provide one of:
  - NIFTY index, signals only (to keep the current read-only example).
  - A specific NIFTY futures expiry or exact OpenAlgo futures symbol.
  - A NIFTY option's expiry, strike and CE/PE, or its exact OpenAlgo symbol.
Use Symbol Search to confirm the contract and current lot size. Do not infer
the lot size from an old example or assume one unit is a valid derivative lot.
The loaded master contract currently includes NIFTY29DEC26FUT on NFO at 65
units per lot. That is an available example, not a selected trade or a promise
that the lot size will remain the same on future dates.

7. ADD AND TEST THE PAPER ORDER LEG AFTER THAT SELECTION
The order leg is not configured yet. Confirm the exact instrument, quantity,
entry rule and exit rule before enabling it. Keep Analyze visible and verify
sandbox orders, trade fills and positions after the test. Do not treat a
signal, an accepted order or a successful API response as proof of a fill.
Historical replay and a real-time Analyzer run are different tests. On a market
holiday, do not substitute old prices and report them as current market fills.

8. RE-RUN THE OFFLINE TESTS
    .\.venv\Scripts\python.exe -m pytest --noconftest test/test_first_nifty_strategy.py -q
15 focused tests passed. They cover crossover direction, completed-candle
